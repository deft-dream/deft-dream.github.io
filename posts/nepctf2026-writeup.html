MISC - 如烟大帝独断万古

这道题考察Unicode变体选择符隐写技术。

Step 1: 观察异常 Unicode 字符

解压后查看 novel.txt，正文没有直接出现flag。但检查字节可以看到大量形如 EF B8 xx 的序列，对应Unicode变体选择符 U+FE00 到 U+FE0F。

这些字符通常不可见或弱可见，刚好对应题面"名讳也是尔等能直呼的？"的暗示：真正的信息没有直接显示在正文中。

Step 2: 提取 Variation Selectors 并解码

将每个变体选择符按如下方式映射为十六进制数字：

U+FE00 -> 0
U+FE01 -> 1
...
U+FE0F -> f

完整解题脚本：

with open('novel.txt', 'rb') as f:
    data = f.read()

# 提取变体选择符
selectors = []
for byte in data:
    if 0xFE00 <= byte <= 0xFE0F:
        selectors.append(byte - 0xFE00)

# 转换为十六进制字符串
hex_str = ''.join(format(s, 'x') for s in selectors)

# 转换为ASCII
flag = bytes.fromhex(hex_str).decode()
print(f"Flag: {flag}")

知识点

  • Unicode变体选择符（Variation Selectors）
  • 隐写术 - 文本隐写
  • 字节级数据分析

MISC - 谁引闪了我的灯

这道题考察ESP32固件逆向和无线协议分析。

Step 1: 提取图片线索

压缩包里有两个文件，JPEG的COM marker中有注释，给出频道和设备ID信息。

Step 2: 逆向固件发包格式

固件是ESP32-S3 Arduino merged flash。分区表显示app位于 0x10000。

用Xtensa反汇编跟到trigger逻辑，可还原出16字节payload的格式：

  • 默认 group = 1
  • 图片给出 id = 19 = 0x13
  • 01 01 是trigger引闪命令字段
  • 最后一字节是前15字节求和取低8位

Step 3: 计算 flag

根据逆向出的协议格式，构造正确的payload即可获取flag。

知识点

  • ESP32固件逆向
  • Xtensa汇编
  • 无线协议分析
  • JPEG文件格式

CRYPTO - Blind RAG

考察线性代数和加密算法分析。

Step 1: 观察查询 oracle 的线性泄露

通过分析oracle的响应模式，发现存在线性关系可以利用。

Step 2: 恢复向量并解密文档

利用线性泄露恢复密钥向量，然后解密目标文档获取flag。

知识点

  • 线性代数
  • Oracle攻击
  • 向量恢复

CRYPTO - LGC Attack

考察线性同余生成器（Linear Congruential Generator）的攻击。

攻击原理

LCG的递推公式为：S_{n+1} = (a * S_n + c) mod m

如果能获取足够多的输出值，可以通过以下方法恢复参数：

  1. 利用连续输出的差值
  2. 计算模数m
  3. 求解乘数a和增量c

知识点

  • 线性同余生成器
  • 格基规约（Lattice Reduction）
  • 密码分析
